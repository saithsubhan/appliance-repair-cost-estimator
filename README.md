# Appliance Repair Cost Estimator

A modern appliance repair pricing calculator designed for homeowners and local appliance repair businesses.

## Overview

This project helps users estimate appliance repair costs based on appliance type, repair category, and service complexity.

The estimator is designed to improve pricing transparency and user experience for appliance repair customers.
